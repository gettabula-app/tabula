section: Added

- Agents on the board: an agent connected through an access token now shows as at work (a cursor named for the member it works for, with its token's name quoted after it, and an avatar in the people list) for a short while after it changes the board. What it creates is marked "Agent draft" until someone edits it or presses **Accept draft**. **Agent activity** in the board menu lists what each agent did, newest first, and an editor can **Revert** one call; whatever people changed since is left alone and the panel says so.
