What goes on the board

Everything a workshop needs, nothing that gets in the way of the conversation.

Notes, shapes, connectors

Drop sticky notes and shapes on a snapping grid. Connectors stay attached when you move things, so a diagram never comes apart.

Flowcharts and UML shapes are built in, and Mermaid import turns text into a diagram.

  • Snapping grid
  • Mermaid import
  • UML shapes
  • Icons

Run the session, not the tool

Step through an exercise with timers. Let everyone write privately, then reveal all notes at once. Vote with dots, run a poll, and keep the discussion in comment threads.

  • Session steps
  • Private writing
  • Dot voting
  • Polls

Yours first, shared second

Every board is stored in your browser and works offline. A small relay syncs cursors, selections and presence when it can be reached, and merges changes later.

Open source. Self-host with Docker, or use a hosted workspace with teams and roles.

  • Offline
  • Live cursors
  • Five themes
  • Roles
