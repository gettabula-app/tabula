# Ordlista, svenska

Översättare följer den här listan. Termer med `?` är osäkra och väntar på Johans svar. Se `_review.md`.

## Regler

- Namn på knappar, menyer och fält står kvar på engelska, i gränssnittets egen ordalydelse, eftersom appen inte har något översatt gränssnitt än. Första gången ett sådant namn förekommer på en sida får det en svensk glosa inom parentes: **Share** (Dela). Därefter bara det engelska namnet.
- Tabula, Claude Code och andra produktnamn översätts inte. Tangentnamn översätts inte (`Ctrl`, `Shift`, `Esc`).
- Skärmdumparna visar det engelska gränssnittet. Det nämns en gång på sidor som har bilder.
- Du-form. Korta meningar. Samma ord för samma sak på alla sidor.
